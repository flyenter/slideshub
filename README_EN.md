# SlidesHub

SlidesHub is a presentation interaction SaaS platform for training, roadshows, meetings, classrooms, and enterprise knowledge sharing. It connects a PowerPoint / WPS add-in, a WeChat Mini Program, backend services, and an admin console into one workflow for live presentations, audience interaction, feedback collection, and post-event data review.

> Audiences do not need to install an app. They can scan a WeChat QR code to join a meeting, watch synced slides, and submit feedback.

## Highlights

- **Live presentation interaction**: Launch surveys, collect responses, and view results during a presentation.
- **Zero-install audience experience**: Attendees join through WeChat without downloading an additional app.
- **Multi-file presentation orchestration**: Arrange multiple PPT files in advance for training, roadshows, defenses, and group presentations.
- **Mobile remote control**: Turn pages, switch files, exit slideshow mode, and check interaction results from the Mini Program.
- **Post-meeting data retention**: Keep attendance records, survey results, slide screenshots, and meeting materials for review and export.
- **Private deployment support**: Suitable for regulated or security-sensitive industries such as finance, healthcare, government, and consulting.


## Key Features

| Feature | Description |
|---|---|
| PPT group management | Create presentation groups, manage multiple files, and reorder them visually |
| Seamless file switching | Switch to the next PPT file during group presentations without manual file handling |
| Automated slideshow | Open files and run slideshows in predefined order through the add-in |
| WeChat QR meeting entry | Let attendees join a meeting, view live slides, and interact from WeChat |
| Mobile remote control | Control PowerPoint / WPS page navigation, file switching, and slideshow exit |
| Page-bound surveys | Bind survey templates to specific PPT pages and trigger them during the presentation |
| Realtime results | Display survey results with bar charts, pie charts, or comparison charts |
| Slide screenshot sync | Sync slide screenshots so attendees can view current content on mobile |
| Protected meetings | Use password-protected meetings for sensitive content |
| Admin console | Manage users, memberships, meetings, surveys, analytics, and audit logs |
| Multilingual UI | Chinese / English support for the add-in and Mini Program |

## Use Cases

- **Corporate training**: Coordinate multiple trainers and decks while collecting training feedback.
- **Sales roadshows**: Let clients scan, follow the deck, and submit intent or preference data.
- **Product launches**: Run live polls and surveys during key product moments.
- **Education**: Help students view slides on mobile and participate in in-class quizzes.
- **Startup pitches and competitions**: Pre-arrange multiple teams' decks and switch quickly on stage.
- **Professional reporting**: Protect sensitive presentations with encrypted meetings and private deployment.
- **Offline conferences**: Combine check-in, slide sync, live surveys, and post-event analytics.
