# SlidesHub

SlidesHub 是一套面向培训、路演、会议、课堂和企业分享的演示互动 SaaS 平台。它将 PowerPoint / WPS 插件、微信小程序、后端服务与管理后台连接在一起，让 PPT 演示、现场互动、观众反馈和会后数据沉淀形成完整闭环。

> 无需观众安装任何 App，微信扫码即可参与互动演示、同步观看投屏并提交调研反馈。

## 核心价值

- **演示与互动实时连接**：演讲者可在演示过程中发起问卷、查看结果、同步观众反馈。
- **观众零门槛参与**：微信扫码进入会议，无需下载 App，无需额外注册。
- **多文件演示顺序编排**：提前组织多个 PPT 文件，适合培训、路演、答辩和多人连续汇报。
- **手机远程控场**：通过小程序远程翻页、切换文件、退出放映或查看互动结果。
- **会议数据沉淀**：参会记录、调研结果、截图和会议资料可留存，便于复盘和导出。
- **支持私有化部署**：面向金融、医药、政务、咨询等对数据安全要求较高的场景。


## 主要功能

| 功能 | 说明 |
|---|---|
| PPT 分组管理 | 创建演示分组，管理多个 PPT 文件，拖拽调整播放顺序 |
| 小组演示切换 | 多位演讲者连续上台时，一键切换下一个 PPT 文件 |
| 自动演示 | 插件自动打开分组文件并进入放映，按顺序完成演示流程 |
| 微信扫码参会 | 观众扫描会议二维码进入小程序，观看投屏并参与互动 |
| 手机远程控制 | 通过小程序控制 PowerPoint / WPS 翻页、切换文件和退出演示 |
| 页面绑定调研 | 将问卷绑定到指定 PPT 页面，演示到该页时自动推送 |
| 实时结果汇总 | 以柱状图、饼图或对比图展示调研结果，支持秒级刷新 |
| 截图同步 | PPT 页面截图同步到云端，观众可在演播厅实时查看 |
| 加密会议 | 支持会议密码保护，适合敏感内容分享 |
| 管理后台 | 支持用户、会员、会议、调研模板、统计数据和审计日志管理 |
| 多语言 | 插件和小程序支持中文 / English 切换 |

## 典型场景

- **企业内训**：多讲师、多课件连续演示，实时收集培训反馈和测验结果。
- **销售路演**：客户扫码同步观看方案，在关键页面提交意向和关注点。
- **产品发布会**：现场观众通过手机参与投票、问卷和互动反馈。
- **教育课堂**：学生在手机端同步查看课件，参与随堂测验。
- **招商宣讲与项目答辩**：提前编排多个团队的 PPT，现场快速切换。
- **专业汇报**：金融、医药、咨询等场景可使用加密会议和私有化部署。
- **线下大会**：会议签到、资料同步、互动调研和会后复盘统一完成。
